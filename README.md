# Две таблицы — CUSTOMERS и ORDERS

## 📋 Описание задачи

Создать две связанные таблицы и написать SQL-скрипты:
1. Создание таблицы `CUSTOMERS` с автоинкрементным первичным ключом.
2. Создание таблицы `ORDERS` с внешним ключом на `CUSTOMERS`.
3. Выборка `product_name` для пользователей с именем `alexey` (независимо от регистра).

## 🎯 Цель

Отработать:
- Создание таблиц с автоинкрементным первичным ключом (`SERIAL` / `AUTO_INCREMENT`);
- Связывание таблиц через **внешний ключ** (`FOREIGN KEY`);
- Написание `JOIN`-запросов;
- Работу с регистронезависимым поиском (`LOWER` / `ILIKE`).
